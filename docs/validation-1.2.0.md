# 1.2.0 build 7 验证记录

日期：2026-11-06。环境：Apple Silicon、macOS 27.2、Safari 27.2、Xcode 27.1。最低运行版本配置为 macOS 13。

## 当前实现

- 保留原生 Liquid Glass 工具栏、完整网址开关、当前引擎双向同步、独立默认引擎与自定义引擎管理。
- 按用户最新要求撤回跨应用 Esc；源码、Xcode 工程和安装包只包含主应用与 Safari 扩展。没有独立按键助手或授权设置，没有全局输入拦截。
- Esc 保留面板内的普通关闭行为；Safari 自身获焦时按键交由 Safari 处理，不承诺全屏下两次 Esc 的优先级规则。
