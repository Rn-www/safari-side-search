# Changelog

## 1.2.1

- 设置改用保持可见的标准窗口，减少菜单操作后窗口自动隐藏的问题；添加表单延后至菜单结束后打开。
- 新增直接可见的“添加搜索引擎…”按钮。名称可留空，支持常见引擎名称/域名补全，或从搜索结果 URL 识别搜索参数。
- 已有引擎直接复用，自定义名称和 ID 保留；支持地址预览和输入提交，兼容原有模板配置。
- 菜单测试改走菜单项派发，增加规范化、自动命名、重复项和默认持久化检查。

## 1.2.0

- Build 7：按用户要求撤回跨应用 Esc 和独立助手，恢复面板内的普通 Esc 关闭行为；保留主应用与扩展沙盒。
- 构建脚本支持主应用和扩展的 Apple Silicon / Intel 通用包。



- 顶部工具栏加入系统原生 Liquid Glass 胶囊控件，新增设置齿轮与 ⌘, 入口；旧系统保留磨砂材质。
- 设置页提供完整网址开关、当前搜索引擎、自定义引擎管理及独立默认引擎。
- 每次右键新搜索使用默认引擎，手动切换只影响当前查询；旧版记忆选择迁移为初始默认。
- 简洁网址与实际导航 URL 分离，编辑时显示完整地址，显示偏好切换不覆盖未提交文字。
- 补充偏好迁移、默认回退、设置同步、单次请求、深浅色与不同宽度的界面检查。
- 搜索页样式恢复加入定时后备调度，避免后台 WebKit 暂停动画帧后延迟恢复。

## 1.1.1

- 增加 Bing 和百度网页搜索的窄侧栏适配，搜索框与结果列随面板宽度重排。
- 长标题、网址与摘要自动换行，右侧卡片排到结果下方，保留正常字号。
- 动态加载、样式和 viewport 重建后自动恢复；离开搜索路径后撤除适配并恢复 viewport。
- 补充 340/430/720 pt 布局、动态结果、站点别名、路径及域名隔离测试，并提供可选实时布局检查。

## 1.1.0

- 预置 Google、Bing、百度和 DuckDuckGo，可在原生侧栏顶部切换，记住上次选择。
- 自定义引擎支持名称与 `{query}` 地址模板，以及添加、编辑和删除。
- 右键选词和地址栏查询使用当前引擎；切换引擎可重新搜索当前查询。
- 增加模板校验、编码、偏好恢复和内建显示屏上的引擎控件测试。

## 1.0.1

- Google 搜索框与结果区自适应窄侧栏宽度，长标题和网址自动换行。
- 将右侧信息卡片排到搜索结果下方，保留正常字体大小。
- 动态页面重建后恢复适配，其他网站和 Google Maps 不注入该样式。
- 增加 340/430/720 pt 布局验证、动态内容及域名隔离检查。

## 1.0.0

- Safari 选词右键 Google 搜索。
- AppKit 原生浏览面板、地址栏、后退、前进与刷新。
- 面板宽度记忆、窗口跟随、快捷键与菜单栏入口。
- 搜索编码与 deep link 校验、WebKit 导航测试。
