# 1.2.1 build 10 验证记录

日期：2026-11-10。环境：Apple Silicon、macOS / Safari 27.2、Xcode 27.1，最低运行版本仍为 macOS 13。

## 行为

设置窗口改为标准 NSWindow，保留浮动层级和内建屏定位，菜单选择后不因应用失活而自动隐藏。新增直接添加按钮，从菜单进入时延后至跟踪结束再呈现表单。

输入支持 Google、Bing、百度、DuckDuckGo 的名称或常用域名，补全 HTTPS、搜索路径和参数；名称留空时自动命名。其他引擎支持粘贴带明确搜索参数的结果页 URL，保留其他参数。已有项会复用，编辑保留 ID，原模板配置兼容。不能从陌生首页推断搜索路径时显示提示；多个候选参数时拒绝猜测。

没有全屏 Esc 功能、全局热键或助手，没有新增权限；主应用和 Safari 扩展保留原沙盒。
